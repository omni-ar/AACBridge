\section{Related Work}
\label{sec:related_work}

This section reviews the fundamental literature underpinning the AACBridge architecture, spanning memory management for Large Language Models (LLMs), edge deployment constraints, augmentative communication interfaces, multimodal sensor fusion, and dialogue state tracking.

\subsection{KV Cache Optimization for LLMs}
The computational bottleneck of auto-regressive generation is well documented, leading to significant research in Key-Value (KV) cache management. Systems like vLLM introduced PagedAttention \cite{pagedattention_vllm} to manage memory blocks dynamically, drastically improving throughput for server-side batched requests. Further optimizations like FlexGen \cite{flexgen} explored offloading attention tensors to slower storage to maximize batch sizes. While these works focus on macroscopic throughput via request batching, AACBridge addresses the distinct problem of isolated, single-batch latency on edge devices. We draw inspiration from sparse attention mechanisms, such as Scissorhands \cite{scissorhands}, which drop uninformative tokens; however, AACBridge operates at a higher abstraction, culling entire semantic contexts rather than individual tokens. Concepts like RadixAttention \cite{sglang_radixattention} reuse cache for shared prefixes, a technique AACBridge adapts for preemptive, sensor-driven context priming rather than prompt-based reuse.

\subsection{On-Device Language Model Deployment}
Deploying multi-billion parameter models on edge hardware is constrained by strict RAM and thermal limits. Solutions like MLC-LLM \cite{mlc_llm} compile models directly to native applications using TVM, while PowerInfer \cite{powerinfer} exploits activation sparsity to achieve fast inference on consumer CPU/GPU hardware. AACBridge leverages the \texttt{llama.cpp} \cite{llama_cpp} engine for its bare-metal ARM64 optimization and custom JNI memory control, allowing precise manipulation of the native ring buffer. This engine is paired with highly compact, capable models such as those explored in the TinyLlama project \cite{tinyllama}, ensuring the system fits within the limited edge memory budget.

\subsection{Augmentative and Alternative Communication}
Traditional Augmentative and Alternative Communication (AAC) systems heavily rely on grid-based interfaces \cite{grid_aac_review}. These require deep hierarchical menu navigation, imposing severe latency on conversational participation. While predictive text systems \cite{predictive_aac_text} have improved typing speeds via n-gram and neural approaches, they remain bound to word-by-word generation. Brain-Computer Interfaces (BCI) \cite{bci_aac_survey} offer direct intent translation but remain largely invasive or clinically restrictive. AACBridge bridges this gap by utilizing non-invasive wearable sensors to bypass menu navigation entirely, enabling zero-shot, full-turn generation based on environmental context.

\subsection{Multimodal Sensor Fusion for Intent Classification}
Robust intent classification requires high-confidence inputs. Surface Electromyography (sEMG) has proven highly effective for discrete gesture recognition, as demonstrated by benchmarks like the NinaPro database \cite{ninapro_emg}. Simultaneously, gaze-based Human-Computer Interaction (HCI) \cite{gaze_hci_survey} provides reliable spatial targeting via dwell-time selection. AACBridge fuses these modalities. We evaluated cross-modal attention mechanisms \cite{cross_modal_attention} to intelligently weight high-dimensional EMG features against low-dimensional gaze vectors, ablating this approach against traditional late-fusion architectures \cite{late_fusion_comparison}. Ultimately, we adopt late fusion to ensure computational efficiency without sacrificing accuracy, as cross-attention failed to justify its architectural complexity.

\subsection{Semantic Drift Detection in Dialogue Systems}
While environmental sensors predict physical context, dialogue often drifts semantically. Traditional Dialogue State Tracking (DST) \cite{dialogue_state_tracking} attempts to model this drift but is often too computationally heavy for continuous background execution on edge devices. Instead, AACBridge utilizes highly distilled sentence embeddings \cite{sentence_transformers}, specifically the MiniLM architecture \cite{minilm}, to compute localized conversational centroids. By evaluating cosine similarity against the primed cache context, the system can detect topic shifts efficiently, gated by a hysteresis margin to prevent cache thrashing.
